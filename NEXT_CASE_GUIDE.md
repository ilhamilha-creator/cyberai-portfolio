# Next Case Study Guide - Send the Link Capstone

## How to Add the Next Case Study

### Step-by-Step Process (Using Week 2 Three-Beat Shape)

**1. Problem Statement**
- Identify a real challenge or problem I solved
- Describe the context and constraints
- Explain why this problem mattered

**2. What I Did**
- Detail the technical approach and tools used
- Explain the decision-making process
- Highlight key challenges overcome

**3. What Came of It**
- Share measurable results and impact
- Document lessons learned
- Note what I would do differently

### Implementation Steps

1. **Create new section in portfolio**: Add a new case study section to the main website (`src/app/page.tsx`)
2. **Follow existing pattern**: Use the same structure as the CyberAI project section
3. **Add images/screenshots**: Place relevant visuals in `public/images/`
4. **Update PROJECT_BRIEF.md**: Add the new case study to the project documentation
5. **Test and deploy**: Ensure the new section displays correctly
6. **Update Claude Project**: Add context to the Claude Project for future iterations

### File Locations to Update

- `src/app/page.tsx` - Add new case study section
- `public/images/` - Add new project images
- `PROJECT_BRIEF.md` - Document the new case study
- `README.md` - Update project overview
